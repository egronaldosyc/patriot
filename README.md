# Патриот

Ежедневная военно-историческая летопись — https://egronaldosyc.github.io/patriot/

Статический сайт на [Astro](https://astro.build), публикуется на GitHub Pages и обновляется сам: рутина-сборщик выпускает номер в артефакт-архив, рутина переноса кладёт его в `data/`, GitHub Actions пересобирает сайт.

## Как это работает

```
Рутина «Патриот» (06:00 МСК)        артефакт-архив «Патриот»
  собирает выпуск на завтра  ──►     data/YYYY-MM-DD.json
                                          │
Рутина «Патриот → сайт» (07:15 и 12:15 МСК, claude.ai/code/routines/trig_019w1nXLTxotpim1UjXynQ92)
  сверяет архив с репозиторием за 20 дней, переносит новые и изменённые файлы байт в байт,
  пушит в main (запасной путь — ветка claude/…, workflow сам перенесёт выпуски в main)
                                          │
                                          ▼
                              Actions: «Сборка и публикация»
                                проверка данных (scripts/validate.mjs)
                                сборка: страницы, карточки-превью, RSS, sitemap
                                поисковый индекс Pagefind
                                          │
                                          ▼
                                    GitHub Pages
```

Токены не нужны: рутина переноса работает через GitHub-подключение аккаунта claude.ai. Рутина-сборщик и очередь Telegram не менялись.

Второй запуск workflow — каждый день в 00:05 по Москве: на главной сменяется «сегодняшний» выпуск. Выпуск, подготовленный накануне, доступен по своему адресу сразу и анонсируется на главной как «Завтра».

## Страницы

| Адрес | Что это |
|---|---|
| `/` | выпуск на сегодня (по Москве) и анонс завтрашнего |
| `/YYYY-MM-DD/` | постоянная страница выпуска |
| `/archive/` | архив: календарь по месяцам и список выпусков |
| `/razdel/<id>/` | раздел сквозь весь архив (`dates`, `vov`, `army`, `security`, `heroes`, `svo`, `weapons`, `word`) |
| `/search/` | поиск по архиву с фильтрами по разделу и эпохе; параметры `?q=&section=&era=` |
| `/about/` | о проекте и правилах |
| `/feed.xml` | RSS |
| `/data/index.json`, `/data/YYYY-MM-DD.json` | открытые данные в контракте сборщика |
| `/og/YYYY-MM-DD.png` | карточка-превью для Telegram и соцсетей |

Старые ссылки вида `/#2026-10-09` перенаправляются на `/2026-10-09/`.

## Данные

Контракт задаёт сборщик и здесь не меняется: один файл на выпуск, `data/YYYY-MM-DD.json` (поля `date`, `title`, `lede`, `epigraph`, `hero_image`, `photo_note`, `sections[]`, `posts[]`, `image_credits[]`). Любое поле может быть `null` или отсутствовать — нормализация в `src/lib/normalize.js`:

- текст выводится только как текст, ссылки — только `http(s)`, в новой вкладке с `rel="noopener noreferrer"`;
- разделы расставляются в порядке `dates → … → word`, неизвестные идут следом;
- пустой раздел показывает `empty_note`, выпуск без фото — `photo_note`;
- фото без прямого адреса показывается подписью со ссылкой; не загрузившееся фото скрывается, подпись остаётся.

`data/index.json` не нужен: сайт собирает индекс из файлов выпусков сам.

## Разработка

Нужен Node.js 22+.

```bash
npm ci
npm run dev                 # http://localhost:4321
npm run validate            # проверка data/
npm run build && npm run preview
```

Переменные окружения:

- `PATRIOT_FIXTURES=1` — подключить тестовые выпуски из `fixtures/` (без фото, пустые разделы, битые данные);
- `PATRIOT_TODAY=2026-10-09` — считать «сегодня» другой датой;
- `SITE_URL`, `BASE_PATH` — адрес сайта и путь; в Actions подставляются автоматически из настроек Pages.

## Публикация выпуска вручную

Закоммитить файл в `data/` — сайт пересоберётся сам. Или запустить рутину переноса вручную на странице рутины («Run now»).

Запасной вариант без рутины — `scripts/publish_issue.py` (GitHub REST API, нужен fine-grained токен с правом Contents на этот репозиторий):

```bash
GITHUB_TOKEN=... python3 scripts/publish_issue.py data/2026-10-09.json
```

## Свой домен

Settings → Pages → Custom domain. Адреса и `base` пересчитаются при следующей сборке, менять код не нужно.

## Устройство

```
src/
  lib/normalize.js     нормализация контракта, разделы и эпохи
  lib/issues.js        загрузка выпусков, «сегодня» по Москве, соседи
  lib/dates.js         даты, склонения, «82 года назад»
  lib/og.js            карточки-превью и иконки (satori + resvg)
  styles/tokens.css    дизайн-токены: цвета тёмной и светлой темы, шрифты, шкала, движение
  styles/global.css    базовые стили, кнопки, анимации появления, view transitions
  components/          шапка, лента дат, герой выпуска, «Главное за день», хронология, разделы, материалы
  pages/               страницы и эндпоинты (RSS, данные, превью, манифест)
  scripts/site.js      тема, копирование, «Поделиться», окна историй, клавиатура (← → — соседние выпуски, / — поиск)
  scripts/search.js    поиск на Pagefind
integrations/search-index.mjs   поисковый индекс: запись на каждый материал
scripts/validate.mjs            проверка данных с аннотациями GitHub Actions
scripts/publish_issue.py        публикация выпуска из рутины
```

Шрифты (Oswald, PT Serif, PT Sans Narrow) подключены локально через Fontsource — сторонних запросов, трекеров и счётчиков нет. Фотографии загружаются с сайтов-источников с `referrerpolicy="no-referrer"`.
